# PaperSwipe · 收藏（Library）

**在 Explore 划走的每一篇论文，都有了一个真正属于你的家。**

---

## 一句话价值

你在首页右划、上划、下划留下的每一篇论文，都会自动分类整理进 Library——按"感兴趣 / 重点 / 已读"清晰归档，随时回来查看完整精读笔记，一键批量导出到 BibTeX 或 Zotero，把"随手一划"真正变成可管理、可复用的文献库。

---

## 核心功能

### 1. 三栏分类，一眼看清阅读进度

Library 把你收藏的论文自动分成三类：

- **Interested（感兴趣）**：首页右划保存的论文，你的待读池
- **Key（重点）**：首页上划标记的论文,是你判断为优先级最高、必须深读的工作
- **Read（已读）**：首页下划标记的论文,归档你已经消化过的成果

每个分类顶部都实时显示数量，一眼就知道自己"攒了多少要读的、读完了多少"，阅读进度清清楚楚。

### 2. 按主题标签筛选，快速定位

Library 会自动从你收藏的论文里提炼出主题标签,点一下标签就能在当前分类里快速筛出某个细分方向的论文,不用在一长串列表里翻找,几秒钟找到你想找的那一篇。

### 3. 点开即是一份完整的精读笔记

点击任意一张收藏卡片,会弹出和首页一致的完整卡片——正面是通俗中文一句话摘要,轻点一下翻到背面,问题、方法、成果、创新点、适合谁读、预估阅读时长、引用次数、原文链接一应俱全。收藏不是简单地存一个链接,而是把当时 AI 帮你精读的全部信息完整保留下来,随时回来都能秒懂这篇论文讲了什么。

### 4. 长按卡片,一步归档或安排阅读

长按任意一张卡片,会弹出两个快捷操作:

- **删除**:不再需要就直接移出 Library
- **加入日程**:为这篇论文挑一个具体日期、设定优先级,安排进你的阅读周计划

收藏之后不再是"存了就忘",而是能真正落地成一个具体的阅读安排。

### 5. 多选批量导出,无缝对接你的文献管理工具

点击顶部导出按钮进入多选模式,支持"全选/清空",然后一键:

- **导出为 BibTeX**:自动生成规范的引用条目(标题、作者、年份、期刊/会议、DOI、链接一应俱全),直接导入你常用的写作工具
- **一键导入 Zotero**:连接你的 Zotero 账号后,选中的论文直接同步进你的 Zotero 文献库,不用再手动一篇篇添加

Library 里筛选出来的每一篇论文,都能无缝流转进你真正的科研工作流,不再是一个信息孤岛。

### 6. 全端同步,随时保持一致

无论在首页划走、在 Library 里整理,还是把某篇标记为已读,所有状态都会实时同步,底部导航栏上的数字角标随时告诉你当前收藏了多少篇——打开 App 的第一眼,就知道自己还有多少论文等着读。

---

## 为谁而做

- **正在写文献综述的研究生/博士生**:把首页筛出来的相关论文集中沉淀在 Library,写作时一键导出成规范引用,省去手动整理参考文献的时间。
- **长期追踪某个方向的研究者**:用"重点"分类标出真正必须深读的关键论文,搭配阅读日程安排,确保重要工作不会被淹没在待读列表里。
- **已经在用 Zotero/BibTeX 管理文献的人**:Library 不是又一个孤立的收藏夹,而是你现有文献管理系统的入口——划走的每一篇,都能一键流入你原本的工作流。

---

## 核心价值主张

传统收藏论文:存进浏览器书签或者一个杂乱的文件夹,过几周再打开,已经忘了当时为什么要存。

**PaperSwipe:每一篇收藏都自带完整精读笔记,按感兴趣/重点/已读清晰归档,还能一键导出进你真正在用的文献工具。**

把"收藏"从一个信息黑洞,变成一个持续生长、真正为你所用的个人文献库——这就是 Library 存在的意义。
