# 宣传页上线：简易步骤

这份说明只发布宣传页，不会覆盖 paperswipe.site 的应用，也不需要上传邀请码、DeepSeek Key、.env 或用户数据。

1. 找到桌面 `黑客松/demo/PaperSwipe-public-20261015.zip`。此包已经包含 `index.html`、图片、样式和你提供的新视频，不需要改文件名。
2. 打开 https://dash.cloudflare.com/ ，注册或登录 Cloudflare。
3. 进入 **Workers & Pages**，点 **Create application**，选择 **Pages / Get started → Drag and drop your files**。不要选择 Worker，也不要选择连接 Git 仓库。
4. 项目名填 `paperswipe-intro`；如果名字已被占用，换一个。上传整个 ZIP。
5. 点 **Deploy site / Save and Deploy**，等待成功后打开页面上显示的 `https://……pages.dev` 链接。这就是可以发给别人的公开地址，以平台实际显示的地址为准。
6. 用手机或无痕窗口打开链接，点“观看演示”检查视频，再点“立即体验”检查是否进入 paperswipe.site 的邀请码登录页面。

以后更新：回到同一个 Pages 项目，选择 **Create a new deployment → Production**，上传新的完整网页包。不要每次新建项目，原网址即可继续使用。

注意：上传包的最外层必须直接包含 `index.html` 和 `paperswipe-assets`，不能在外面再套一层文件夹。本次已经按这个结构打包。

Cloudflare Pages 单个文件上限为 25 MiB，本次视频已转成约 4.5 MiB 的浏览器兼容版本。原始视频未被修改。此方案提供公开 HTTPS 链接，但各地区访问速度取决于网络；如果主要面向中国大陆用户，后续可改用已有腾讯云服务器的独立子域名，避免覆盖现有应用。

本次没有自动上传或发布；只有完成上面的上传部署后，别人才能通过公网链接看到。

官方步骤：https://developers.cloudflare.com/pages/get-started/direct-upload/
