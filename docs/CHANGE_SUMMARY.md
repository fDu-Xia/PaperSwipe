# Summary

优化 AI 论文摘要与渐进式卡片加载，完善阅读偏好、主题切换及移动端交互

# Description

## AI 摘要与等待体验

- 首批最多 4 张卡片生成后即可阅读，后续按检索顺序追加到卡堆底部，不必等待全部 20 篇处理结束。
- 优先启动前序批次，保留最多 3 批并发；不更换模型、不减少最终论文数量。
- 已展示卡片保持最终内容；后续批次、重复数据及完成事件不重置翻面、阅读位置或覆盖当前卡片。
- 划完已生成卡片时等待下一批；连接中断时保留已经生成的内容。
- 优化正面一句话摘要：聚焦论文核心问题或发现，使用具体、精简的日常中文，保留证据范围与不确定性，避免空泛概括和夸张表达。
- 根据搜索提交时的身份与阅读难度生成摘要；只依据标题和摘要，不声称读取全文。
- 移除卡片内 AI 状态和重新生成控件，保留正反面内容布局；搜索不自动重写 Library 收藏。

## 检索稳定性与缓存

- 修复连续更新主题时旧请求干扰新结果的问题，增加请求取消与过期结果隔离。
- 对论文源暂时性错误进行受限重试，区分空结果与源不可用，保留多源回退。
- 阅读身份、难度与 Focus/Broaden 设置参与生成及候选选择。
- 完整成功的搜索结果按账号、主题、偏好和模型配置缓存 30 分钟，支持相同请求合并；失败或部分结果不缓存。
- 新增主动刷新入口；缓存命中不重复调用 AI，内测搜索缓存命中不占生成额度。

## 界面与交互

- 阅读身份改为符合 PaperSwipe 主题的自定义选项面板，补充展开、选择和关闭动画及键盘操作。
- 优化详情卡片关闭、邀请码页点击及反馈动画，并兼顾减少动态效果设置。
- 深色模式使用黑色底与柔和光晕，修正卡片背面配色和可读性。
- 统一 Schedule 任务块色调，移除突兀的高光与杂色渐变。
- 修复设置页滚动和布局问题，保留移动端使用体验。

## 验证与发布说明

- Go 单元测试、静态检查及浏览器模拟流式测试覆盖主要逻辑。
- 浏览器验证首批提前显示、后续追加、翻面保持、重复/迟到数据忽略、等待下一批及断线保留。
- 渐进加载缩短的是开始阅读前的等待，不承诺模型总生成耗时下降；实际速度仍受模型及网络影响。
- 当前为本地修改，尚未 push 或部署；重启本地 Go 服务并刷新页面后使用新版。
- 不要提交 `.env.local` 等密钥文件。`data/state.json` 是运行产生的用户状态，应与代码修改分开审核。
